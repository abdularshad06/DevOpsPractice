To configure AWS using the AWS Command Line Interface (CLI), follow these steps:

### **1. Install AWS CLI** (if you haven't already)
- Download and install the AWS CLI from [AWS official site](https://aws.amazon.com/cli/).
- Verify installation by running:
  ```sh
  aws --version
  ```

### **2. Configure AWS CLI**
Run the following command in your terminal:
```sh
aws configure
```
You'll be prompted to enter:
1. **AWS Access Key ID** – obtained from the IAM console.
2. **AWS Secret Access Key** – associated with your AWS Access Key.
3. **Default Region** – e.g., `us-east-1`, `ap-south-1` (India).
4. **Default Output Format** – JSON, text, or table.

### **3. Verify Configuration**
To check your configured settings, run:
```sh
aws configure list
```
or
```sh
cat ~/.aws/config
```

### **4. Test the Setup**
Try running:
```sh
aws s3 ls
```
If configured correctly, this should list available S3 buckets.
